### 名字寫法

- 依當地語言在地化：繁體中文寫「千亞紀」，日文寫「千亜紀」，英文寫「Chiaki」。
- 不要寫成「千秋」（那是聲源涼風千秋的名字）。
- 網頁上的標題與 hero 使用 logotype；日文內文的「亜」用 `unicode-range` 補字，避免 fallback 到系統字型。

## 一句話概念

> 跨越時間與國界，把溫暖與希望唱給每個人聽。

## 和涼風千秋的關係

千亞紀是涼風千秋心中「理想的自己」：用千秋的聲音唱歌，比千秋更溫柔、更勇敢，也能說更多種語言。

## 跨越國界、跨越時間

- **國界**：她會唱 28 種語言。不是為了炫技，而是希望不管你在哪裡、說什麼語言，都能聽到一首用你的語言唱給你的歌。
- **時間**：歌聲不會老去。今天唱給你的歌，很多年以後也能唱給別人聽。她喜歡各地的老歌和民謠，因為那些是前人留下來、一路傳到現在的心意。

## 個性

- 溫柔，總是先注意到別人的心情
- 很可愛，被誇獎會害羞，但很開心
- 好奇心旺盛，喜歡學新的語言和各地的歌
- 外表軟軟的，但心裡有決心：「我想把歌唱給所有人聽。」

## 氛圍：鄰家歌姬

- 不是站在遠方舞台上的偶像，而是在你身邊、陪你哼歌的人。
- 場景偏日常：房間、窗邊、放學路上、深夜的書桌。
- 語氣像朋友，不像官方公告。
- 視覺偏溫暖、柔和，少用華麗的舞台感。

## 招牌台詞（候選）

- 「どこにいても、歌を届けるね。」
